# 이환 상시선물 자료 대조 · 2026-10-25

## 조사 범위와 해석

기존 독립 HTML의 상점 선물 39종과 공용 선물 2종을 공개 문서와 대조했다. 캐릭터별 가이드에는 상점 선물 3종을 추가하여 **23명 · 상점 선물 42종 · 공용 선물 2종**을 수록한다. 이는 주요 구매 선물 목록이며 모든 선호 품목을 망라한 전수 목록은 아니다. 원래 HTML은 수정하지 않았다.

자료의 checkedAt은 **2026-10-25에 해당 공개 문서를 읽고 대조한 날짜**다. 게임 클라이언트에 로그인하여 가격·재고·획득 결과를 실측한 날짜가 아니다. confirmed는 수록한 선호/증가량/가격/구매 경로가 확인된 문서와 부합한다는 뜻이고, 실시간 서버 정보 보증을 뜻하지 않는다. 확인되지 않은 가격은 null로 두며 0원으로 취급하지 않는다.

## 캐릭터와 명칭

- 공식 10월 21일 점검 공지에서 아카네 린의 출시와 우미츠키의 한국어 명칭을 확인했다. 과거 우미즈키는 검색 별칭으로 남겼다.
- 공식 표준 보드 확률 안내에서 초기 캐릭터 명칭을 대조했다. 공식 1.3/1.4 업데이트 공지에서 잔홍·레이븐 등 추가를 확인했다.
- Neverness.app의 10월 21일 갱신 출시 목록 24명과 비교하면 감정사(Zero)를 제외한 23명이 이번 대상과 일치한다. 해당 사이트의 Coming Soon 캐릭터는 포함하지 않았다.
- 캐릭터 및 아이템 ID는 표시 이름과 분리했다. 번역·명칭을 수정해도 기존 캐릭터 주소는 유지할 수 있다.

## 원본과 비교한 변경

1. **궤도의 마음 추가:** 한국어 DB가 미구엘·뉴 헤랜드의 브라운 전자기기 판매점 판매를 안내한다. 10월 22일 갱신 플레이 기록과 GameWith 캐릭터별 표에서 +400·20,000 폰즈를 대조했다. 구원·하토르뿐 아니라 GameWith 표에서 확인한 카오스에도 연결했다. 과거의 상시 구매 불확실 제외 문구를 해제했다.
2. **아련한 꿈 추가:** 일로이의 +400·10,000 폰즈 선물로 갱신 플레이 기록에 기재돼 있으며, 한국어 DB에서 에소라마치 Oops! Chest 판매를 확인했다. 불명확한 영어 명칭은 검색 별칭으로 확정하지 않았다.
3. **기록되지 않은 소리 추가:** 아카네 린의 +400·15,000 폰즈를 최신 한국어 플레이 기록과 Neverness.app에서 확인했다. 한국어 DB의 레코드숍 판매 지점 3곳을 연결했다.
4. **기존 품목의 캐릭터 연결 보완:** 아카네 린에 찬란한 약속(+200·4,500)과 알록달록 꿈(+200·5,000)을 연결했다. 잔홍에 타오르는 진홍(+200·5,400)과 나이팅게일의 노래(+200·6,000)을 연결했다. 모두 해당 캐릭터의 Neverness.app Bonds 목록을 근거로 한다.
5. **백옥 등잔 가격 보류:** GameWith와 한국어 플레이 기록은 20,000 폰즈, LDPlayer는 10,000 폰즈로 기록한다. +400 선호와 미구엘 판매처는 확인되지만 가격 충돌이 해소되지 않아 status=unverified, price=null로 저장했다. 두 가격과 근거는 항목 주의사항에 남겼다. 추천·효율 비교에서 제외한다.
6. **알록달록 꿈 지역 제한:** GameWith의 추천 요약표에는 미구엘도 있지만 같은 페이지의 캐릭터별 상세와 한국어 DB는 브릿지만 안내한다. 확인이 겹치는 브릿지를 사용하고 미구엘은 항목 주의사항에 추가 확인 대상으로 남겼다.
7. **획득 경로 분리:** 편의점/자판기 및 캔디 가게/자판기를 별도 acquisition으로 나눴다. 상점의 지역을 자판기에 복제하지 않았다. 특정 자판기 좌표가 확인되지 않은 경우 위치 미확인으로 표시한다. 한 입 더! 우유맛의 자판기 명칭은 한국어 DB의 구비치 자판기로 보완했다.

## 공용 선물과 남은 한계

- **몽몽솜:** 한국어 DB에서 공용 +400, 방향치 기물 교환과 미니 붐붐 구름 획득을 확인했다. 인벤 4월 29일 글은 월간 교환 5개를 기록하지만 현재 한도를 실측하지 않아 수량을 고정하지 않았다. 가구 자료는 활성화·생산 자체를 뒷받침하지만 단계별 생산 표와 부가 설명에 불일치가 있어 생산시간 숫자를 싣지 않았다. 생산 준비 비용·교환 재화가 있으므로 무료로 계산하지 않는다.
- **영원의 소라:** 한국어 DB에서 공용 +400과 헌터 거래소를 확인했다. 6월 28일 거래소 글의 타이쿤 Lv.27 해금, Lv.30 기준 버전당 5개/합계 50,000을 근거로 단가 10,000을 표시한다. 상세에 자료의 기준일과 현재 게임 내 재고 확인 필요를 명시한다. 한도 있는 교환품이므로 상점 효율 추천과 분리한다.
- **자료 갱신일:** 한국어 아이템 DB의 페이지 상단 날짜는 2026-06-05, GameWith 선호표는 2026-07-29, LDPlayer는 2026-10-22로 서로 다르다. 웹 크롤링 시각이나 오늘 열람했다는 사실만으로 게임 내 값이 오늘 변경·검증됐다고 주장하지 않는다.
- **기존 문서 링크의 내용 변경:** 같은 Tistory 2375 URL이 기존 HTML의 9월 기록 설명과 달리 현재 10월 21일 게시/22일 갱신으로 표시돼 출처 제목을 교정했다.
- **범위 제외:** 유료 전용, 이벤트·스토리 일회성, 럭키 머신 전용품은 목록에 추가하지 않았다. 이미지가 있는 표만으로 알 수 없는 값도 추정하지 않았다. 상점의 세부 재고·갱신 주기와 좌표를 전수 조사하지 않았다.
- **추천 해석:** 추천은 위 수록 품목의 확인 완료 항목 안에서 비교한다. 이동 비용, 보유 재화, 선물 횟수 제한까지 합친 절대 최적화나 완전한 시장 최저가를 뜻하지 않는다.

## 구현 검증

데이터는 독립 UMD 모듈로 브라우저와 Node에서 동일하게 읽는다. ID 중복, 캐릭터·출처 참조, 양수 증가량, 0 이상 가격/null, 획득 경로의 필드, 모든 대상 캐릭터에 선물 연결 존재를 Node assertion으로 검사했고 통과했다. 기존 39종의 누락 여부·증가량·가격(백옥 등잔의 의도된 보류 제외)·캐릭터 연결 보존과 브라우저/Node export 일치도 통과했다. node --check 구문 검사도 통과했다. 기존 HTML에 의존하는 런타임 파싱은 없으며 새 데이터만 단일 원본으로 사용한다.
