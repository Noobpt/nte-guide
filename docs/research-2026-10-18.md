# 조사 및 구현 기록 · 2026-10-18

## 목적과 범위

기존 이환 가이드를 네 게임의 개인 게임 메모장으로 확장했다. 상설 일간·주간 반복 항목, 별도 회차의 보상, ARC Raiders의 출격 준비를 조사했다. 신규 팁 공략은 작성하지 않고 사용자가 직접 기록할 공간만 제공했다. 기존 이환 팁과 호감도 자료는 보존했다.

이번 자료는 **2026-10-18 시점의 문서 조사**다. 게임 계정에 접속해 실제 화면을 실측한 결과는 아니며, 실시간 이벤트·주간 목표·최신 메타를 자동 수집하지 않는다.

## 이환

- 기존 19개 일간·주간 항목과 출처를 보존하고 현재 공략과 1.3·1.4 공지를 대조했다.
- 본성 픽셀과 활약도, 누적 카페 수익, 가구 생산, 선택 수집 활동을 구별한다.
- 이상 순례는 보스별이 아닌 주간 합계 3회로 관리한다.
- 타이쿤 지원금은 핑크퍼스·배구·전시의 공유 한도다. 일반 주간과 다른 회차로 분리했다.
- 연못 소원 등 개인 재이용 시간의 여지가 있는 항목을 일괄 일일 초기화로 단정하지 않았다.
- 일본 공략의 05시 안내만으로 한국 계정 초기화 시각을 확정하지 않고, 기본값은 수동으로 두었다.

## ARC Raiders

**10월 8일 Frozen Trail 2.0 개편을 우선 적용했다.** 이전 위키의 Cred·일일 보상 수치가 현재 공지와 달라 그대로 가져오지 않았다.

- Feats: Easy / Medium / Hard는 각각 Reward Points 15 / 25 / 50, 주간 진행도 1 / 2 / 3.
- 주간 진행도 4 / 8 / 12의 세 단계는 각각 250 Reward Points. 앱은 완료한 단계 수 0~3으로 기록한다.
- 활성 Reward Pass 확인을 매일의 점검 루틴으로 제공한다. 새 일일 보상으로 계산하지 않는다.
- 주간 Trials와 Feats 주간 단계는 별도 항목이다. 시즌 6 공식 문서에서 주간 목표가 유지됨을 확인했다. 구시즌의 정확한 별 점수 기준은 고정하지 않았다.
- 탄약 일일 구매 한도와 Nomadic Envoys 주간 품목은 선택 구매로 둔다.
- 최신 일간·주간 초기화 시각의 권위 있는 근거가 부족하여 수동 초기화를 기본으로 적용한다.

출격 준비는 게임의 강제 과제가 아니라 장비·손실·탈출 규칙을 바탕으로 재구성한 개인 점검표다. 무기·탄종·탄약, 실드와 증강 장비, 회복과 퀵 슬롯, Safe Pocket, 퀘스트 도구, 가방, 탈출 계획, 파티 설정을 확인한다. 무료 로드아웃의 Safe Pocket 부재와 촬영 퀘스트의 카메라 필요도 반영했다. 탄약·회복 아이템의 보편적 ‘필수 개수’는 설정하지 않았다.

## 검증 범위

`node --test tests/core.test.cjs`의 8개 테스트 통과:

1. KST 월요일 05시 직전·직후의 일간/주간 경계와 다음 초기화.
2. 서버 UTC 오프셋과 기기 시간대·DST 독립성.
3. 게임·주기별 수동 초기화의 격리, 메모·출격 계획 유지.
4. 초기화 설정 변경 시 현재 횟수 유지, 만료된 체크 미복구.
5. 기존 이환 19개 체크와 선택 목록별 시작 날짜 이전.
6. JSON 왕복, 잘못된 형식·중복 ID·범위 오류 거부, 텍스트 보존.
7. 숨긴 과제의 분모 제외, 부분 완료 횟수와 상한.
8. 데이터의 고유 ID·출처 참조·게임·주기 일관성.

JavaScript 구문 검사도 통과했다. 실제 브라우저 검수는 환경 제한으로 미완료다. Python 정적 서버의 로컬 소켓 바인딩은 WinError 10013으로 거부됐고, 브라우저는 정책상 `file://` 탐색을 차단했다. 보안 제한을 변경하거나 우회하지 않았다.

브라우저에서 남은 확인: 화면 폭 1440/390px의 레이아웃, 체크·필터·키보드 포커스, 메모 모달, 실제 파일 다운로드·업로드, 새로고침 후 유지. HTTP와 로컬 파일, GitHub Pages는 저장 영역이 다르므로 같은 주소에서 확인해야 한다.
