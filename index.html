덜 움직이고, 덜 쓰는 방법

도시 일상은 모두 할 필요가 없습니다

일반 배송·낚시·미니게임은 같은 도시 활력을 쓰는 대안입니다. 현재 필요한 부가 보상이 있는 활동 하나를 정해 소모하고, 특별 배송만 별도로 챙기세요.

보상 상한을 본 뒤 반복하세요

마몬은 기록 향상분만 추가 지급됩니다. 지원금을 다 썼다면 핑크퍼스·배구·전시를 더 돌려도 같은 지원금 수입이 늘지 않습니다.

가구는 일괄 수령, 카페는 보충 간격 확보

가구를 받으려고 집을 순회하지 마세요. 카페는 장시간 보충이나 해금된 자동 보충을 쓰고, 배달 수수료가 부담되면 장보기와 선물 구매를 같은 동선에 묶으세요.

선물은 목표 캐릭터부터

폰즈가 부족하면 저렴한 선물의 100P당 비용을 비교하세요. 빠른 호감도 상승과 최저 비용은 다른 목표입니다. 기존 선물표에서 가격·구매처 확인

수집형 일과는 목표가 끝나면 줄이세요

일로이 동물 보상에는 누적 상한이 있습니다. 연못·치안 상점도 원하는 보상을 얻은 뒤에는 매일 전 지역을 순회하는 우선순위를 낮춰도 됩니다.

최초 보상과 시즌 진행도를 현금 수입으로 더하지 않기

1.4에서는 타이쿤 프로젝트의 폰즈 누적 속도가 조정됐습니다. 프로젝트 진행 수치가 실제 지갑 수입과 같다고 가정하지 말고, 반복 보상과 별도로 보세요. 공식 1.4 공지 · 신규 기능

효율 팁은 위에 연결한 보상·주기 규칙을 바탕으로 제안한 동선입니다. 모든 선택 항목을 매일 완료해야 한다는 의미는 아닙니다.

무료로 올리려면

현재 가이드는 HTML 두 파일만으로 동작합니다. 서버 프로그램이나 유료 데이터베이스 없이 공개할 수 있습니다.

Cloudflare Pages — 파일 업로드가 간단

이 가이드처럼 정적 파일만 제공하면 무료 플랜으로 시작할 수 있고, 정적 파일 요청은 무료·무제한으로 안내됩니다. 기본 pages.dev 주소를 사용하면 별도 도메인 구매가 필요 없습니다.

  1. Cloudflare 계정에서 Workers & Pages → Create application → Get started → Drag and drop your files를 선택합니다. 화면 구성이 바뀌면 아래 공식 Direct Upload 안내를 따르세요.
  2. 제공한 ZIP 또는 압축을 푼 폴더를 업로드합니다. index.html이 최상위에 있고 선물 HTML도 같은 위치에 있어야 합니다.
  3. 프로젝트 이름을 정해 배포하면 주소가 발급됩니다. 수정 시 같은 프로젝트에 두 파일을 다시 업로드합니다.

직접 업로드는 나중에 같은 프로젝트를 Git 연동으로 전환할 수 없습니다. 자동 배포가 필요해지면 Git 연동 프로젝트를 새로 만드세요. 드래그 업로드 한도는 1,000파일·파일당 25 MiB이며 현재 가이드는 충분히 작습니다.

GitHub Pages — 수정 이력을 남기고 싶다면

GitHub Free의 공개 저장소에서 무료로 사용할 수 있습니다. HTML을 저장소에 올리고 Pages를 설정하면 github.io 주소로 공개됩니다.

파일을 자주 고치거나 변경 내역을 남기기 좋습니다. 저장소 공개에 익숙하지 않다면 지금은 Cloudflare의 직접 업로드가 더 단순합니다. GitHub 공식 · Pages 무료 조건

체크 기록은 방문자별로 따로

공개 사이트에서도 각자의 브라우저에 저장됩니다. 다른 사람의 완료 상태가 섞이지 않으며, 같은 사람의 휴대폰과 PC 사이에도 자동으로 공유되지는 않습니다.

로컬 파일에서 쓰던 체크는 새 웹 주소로 자동 이전되지 않습니다.

조사 기준과 출처

2026년 10월 5일 확인 가능한 공개 자료를 대조했습니다. 공식 업데이트 공지로 공유 지원금·일괄 수령 등 변경 사항을 우선 반영하고, 개별 콘텐츠 공략으로 위치와 주기를 보완했습니다. 특정 서버의 시각을 확인하지 못한 상태에서 한국 시간으로 임의 환산하지 않았습니다.

같은 재화를 쓰는 여러 활동은 대안으로 묶었습니다. ‘활약도 수령’과 ‘픽셀 소비’는 하나의 일일 행으로, 일반 배송·어시장 판매의 소비량은 주간 도시 활력에 포함했습니다. 완료 체크는 사용자가 판단하며, 게임 계정의 실제 진행 상황을 자동 조회하지 않습니다.
