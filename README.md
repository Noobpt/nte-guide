# 게임 노트

이환 전용 숙제표를 **이환 · ARC Raiders · 명조 · 젠레스 존 제로**를 함께 관리하는 개인 게임 메모장으로 확장했습니다. 별도 서버나 빌드 과정 없이 GitHub Pages에서 실행되는 HTML/CSS/JavaScript 프로젝트입니다. Firebase Google 로그인과 Firestore로 기기 간 기록을 동기화합니다.

[게시된 사이트](https://noobpt.github.io/nte-guide/) — 로컬 수정사항은 저장소에 반영·배포한 뒤 이 주소에 표시됩니다.

## 사용

- 게시된 사이트에서 **Google로 로그인**하면 PC와 휴대폰에서 같은 계정의 기록을 이어 씁니다. 클라우드 사용은 메모장 소유자의 계정으로 제한됩니다.
- 로그인하지 않아도 브라우저에 저장하며 사용할 수 있습니다. 로그인은 승인된 HTTPS 도메인 또는 localhost에서 사용합니다.
- **숙제 모아보기**: 게임별 일간·주간·별도 주기 확인, 완료 체크, 횟수 카운터, 검색.
- **선택도 보기**: 해금 조건·구독·추가 파밍 등 선택 과제를 표시합니다.
- **내 숙제**: 게임과 주기, 목표 횟수를 지정해서 직접 추가·수정·삭제합니다.
- **상세 · 출처**: 설명, 출처 링크, 기본 항목 숨기기를 제공합니다. 숨긴 항목은 설정에서 복구합니다.
- **출격 준비**: ARC Raiders의 장비·실드·탄약·안전 주머니·퀘스트 도구·탈출 계획을 점검합니다. `새 출격`은 체크만 비우며 출격 메모는 유지합니다.
- **메모 · 팁**: 게임별 기록 작성·수정·삭제·검색·고정. 신규 팁은 미리 채우지 않았습니다.
- **설정 · 백업**: 초기화 기준 변경, JSON 내보내기·복원. 복원 전 기록 수를 확인하고 교체하며 직후 되돌리기가 가능합니다.

## 저장과 초기화

로그인 전에는 현재 브라우저에 저장하고, 로그인 후에는 Firebase로 동기화합니다. 처음 비어 있는 클라우드에는 이 브라우저의 기존 기록을 가져옵니다. 클라우드 기록이 이미 있으면 **계정 · 동기화 → 이 브라우저의 이전 기록 가져오기**로 합칠 수 있습니다.

열린 페이지의 오프라인 변경은 해당 계정의 기기 저장 공간에 대기합니다. 같은 항목의 동시 수정은 사용자에게 선택을 요청하고, 메모는 두 사본 모두 남길 수 있습니다. 브라우저 데이터를 지우기 전 동기화 상태를 확인하거나 JSON을 백업하세요. `file://`, `localhost`, GitHub Pages는 서로 다른 저장 공간입니다. 자세한 구성과 검증 범위는 [클라우드 동기화 문서](docs/cloud-sync.md)를 참고하세요.

| 게임 | 기본 초기화 | 이유 |
| --- | --- | --- |
| 이환 | 수동 | 한국 계정 시각을 확정할 공식 근거가 부족해 자동 적용하지 않음 |
| ARC Raiders | 수동 | 최신 Feats·Trials의 정확한 한국 기준 갱신 시각을 확인하지 못함 |
| 명조 | Asia 서버, 일간 05:00 KST / 주간 월요일 05:00 KST | UTC+8 서버의 04:00 기준 |
| 젠레스 존 제로 | Asia 서버, 일간 05:00 KST / 주간 월요일 05:00 KST | UTC+8 서버의 04:00 기준 |

설정에서 **서버의 UTC 오프셋·서버 초기화 시각·요일**을 변경할 수 있습니다. 서버를 바꿀 때 현재 유효한 체크는 유지합니다. 자동 초기화는 다음 접속·화면 복귀·30초 점검 시 표시되며, 기기 시간대와 관계없이 명시한 서버 시간대로 계산합니다.

`별도 주기 · 시즌`과 `출격 준비`는 자동 초기화하지 않습니다. 특히 별도 주기의 항목은 서로 마감일이 다르므로 해당 항목만 체크 해제하세요. `새로 시작`은 해당 게임·주기 전체를 비웁니다. 수동 초기화·삭제 직후의 `되돌리기`는 다음 변경 전까지 유효합니다.

## 기존 이환 자료

- `nte-routines-legacy.html`: 기존 숙제·팁 원문 보존. 새 노트와 체크 상태는 별도로 관리됩니다.
- `이환_상시_호감도_선물.html`: 기존 호감도 선물 자료 보존.
- 기존 `nte-guide-routines-v1` 체크는 같은 주소·브라우저에서 처음 새 노트를 열 때 한 번 이전합니다. 기존 저장 키는 지우지 않습니다. 이환의 과거 선택 항목 초기화 날짜도 보관합니다.

## 구조와 검증

- `assets/data.js`: 게임·과제·출처 데이터. 기준일 **2026-10-18**.
- `assets/nte-legacy-data.js`: 이전 과제와 출처, 마이그레이션 매핑.
- `assets/core.js`: 초기화·저장 형식·백업 검증·이전 로직. 브라우저와 Node에서 공유.
- `assets/app.js`, `assets/styles.css`: 화면·상호작용·반응형 스타일.
- `assets/sync-core.js`, `assets/cloud.js`: 충돌 병합 모델과 Firebase 로그인·동기화.
- `firestore.rules`: 소유자 접근 제어와 데이터 검증.
- `docs/cloud-sync.md`: Firebase 구성·저장 모델·운영·검증 범위.
- `docs/research-2026-10-18.md`: 조사 범위, 변경사항, 출처와 확인 한계.

핵심 상태 로직 검증:

```powershell
node --test tests/core.test.cjs tests/sync.test.cjs
```

로컬 HTTP 실행이 가능한 환경:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Firebase SDK를 공식 gstatic CDN에서 불러옵니다. 기본 노트 기능은 SDK 로딩 실패 시에도 브라우저 저장으로 동작합니다. 관리자 비밀 키는 사용하지 않습니다. 메모 내용은 HTML로 실행하지 않고 텍스트로 표시합니다.

로컬 HTTP 및 `file://` 검수는 환경에서 차단되어, 실제 화면 검수는 게시된 HTTPS 사이트에서 수행합니다. 게임 자료의 확인 범위는 조사 문서, 동기화 검증 범위는 클라우드 문서에 기록합니다.
